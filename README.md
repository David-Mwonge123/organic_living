# Organic Living Restaurant
> A responsive farm-to-table restaurant landing page that promotes healthy and organic dining,where the products are sourced directly from local farmers.
## Project Brief
Organic living is a single-page landing website for a fictional organic restaurant in Nairobi. It focuses on nutrition and very attentive to what consumers eat. Organic living is dedicated to not only satisfy hunger, but to also add necessary nutrients to the body for longevity.
